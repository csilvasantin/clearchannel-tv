# Experto mínimo y Bugito / Minimum Expert and Bugito

ES: Abre Experto: queda una línea escribible de 52 px. Arrastra el tirador superior, usa las flechas, Inicio o doble clic para ajustar su altura. Cerrar y reabrir vuelve al mínimo. `/bugito` muestra u oculta a Bugito flotando en la página. `/bugito full` o `/bugito avanzado` abre el banco de pruebas; `/admirito` restaura la nube.

EN: Open Expert for a writable 52 px line. Drag the top handle, use arrow keys, Home or double-click to resize. Reopening starts at minimum. `/bugito` toggles floating Bugito on the page. `/bugito full` or `/bugito avanzado` opens the test bench; `/admirito` restores the cloud.
